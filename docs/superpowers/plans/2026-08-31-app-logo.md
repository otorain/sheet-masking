# 应用 Logo 生效 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让新的 `public/logo.png`（1024×1024 PNG）在页面 favicon、窗口/任务栏图标、Windows NSIS 安装包（exe）三处生效，并删除模板遗留的 logo.svg。

**Architecture:** 图标分三层：渲染页 favicon 由 `index.html` 引用 `public/` 内文件（vite build 会把 public/ 拷入 dist/）；Electron 窗口图标由 `electron/main/index.ts` 的 `BrowserWindow.icon` 在运行时从 `process.env.VITE_PUBLIC`（dev = public/，prod = dist/）读取；打包产物图标由 `electron-builder.json` 的 `win.icon` / `linux.icon` 在打包时读取 `build/` 目录。Windows 需要多尺寸 .ico（ImageMagick 已装：`/usr/bin/magick`）。

**Tech Stack:** ImageMagick（生成 ico/png）、electron-builder 26.8.1（打包图标）、Electron 42。

## Global Constraints

- 主要平台为 Windows；本机（Linux）只做本地验证，Windows 包由用户自行构建验证（wine docker 方案见 AGENTS.md，本计划不执行）
- 不引入新 npm 依赖（ImageMagick 系统已装）
- `build/` 目录不在 .gitignore 中，图标文件会随代码提交
- 提交信息：英文 conventional commits，直接提交 main
- 界面/文档文案中文（本次无新增文案）

### Task 1: 生成图标文件

**Files:**
- Create: `public/favicon.ico`（多尺寸 ico，运行时窗口图标）
- Create: `build/icon.ico`（electron-builder win 打包图标，与 favicon.ico 同文件）
- Create: `build/icon.png`（512×512，electron-builder linux 打包图标）

**Interfaces:**
- Consumes: `public/logo.png`（已存在，1024×1024 RGBA）
- Produces: `public/favicon.ico`（16/24/32/48/64/128/256 多尺寸）、`build/icon.ico`、`build/icon.png`（512×512）

- [ ] **Step 1: 生成 favicon.ico 与 build/ 图标**

```bash
mkdir -p build
magick public/logo.png -define icon:auto-resize=256,128,64,48,32,16 public/favicon.ico
cp public/favicon.ico build/icon.ico
magick public/logo.png -resize 512x512 build/icon.png
```

- [ ] **Step 2: 验证产物格式**

```bash
magick identify public/favicon.ico build/icon.png
```

Expected: `public/favicon.ico` 列出多个尺寸条目（ICO 256×256、128×128、64×64、48×48、32×32、16×16），`build/icon.png` 为 PNG 512×512。

- [ ] **Step 3: 提交**

```bash
git add public/favicon.ico build/icon.ico build/icon.png
git commit -m "feat: add app icons (multi-size ico + 512px png)"
```

### Task 2: 接入 favicon 与窗口图标

**Files:**
- Modify: `index.html:5`
- Modify: `electron/main/index.ts:65`
- Delete: `public/logo.svg`

**Interfaces:**
- Consumes: Task 1 生成的 `public/favicon.ico`、`public/logo.png`
- Produces: dev/prod 下 `BrowserWindow` 图标与页面 favicon 均为新 logo

- [ ] **Step 1: index.html favicon 指向新 logo**

`index.html:5` 改为：

```html
<link rel="icon" type="image/png" href="/logo.png" />
```

（原值为 `type="image/svg+xml" href="/logo.svg"`）

- [ ] **Step 2: 窗口图标平台区分**

`electron/main/index.ts:65` 改为：

```ts
icon: path.join(process.env.VITE_PUBLIC, process.platform === 'linux' ? 'logo.png' : 'favicon.ico'),
```

（原值无条件指向 `favicon.ico`。Linux 下 Electron 窗口图标只吃 PNG，Windows 吃多尺寸 ico）

- [ ] **Step 3: 删除模板遗留 svg**

```bash
rm public/logo.svg
```

（改引用后已无任何地方使用；`src/assets/vue.svg`、`src/assets/vite.svg` 是模板资源，本次不动）

- [ ] **Step 4: 提交**

```bash
git add index.html electron/main/index.ts public/logo.svg
git commit -m "feat: use new logo for renderer favicon and window icon"
```
