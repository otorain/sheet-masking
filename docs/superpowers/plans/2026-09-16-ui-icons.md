# 界面图标补齐实现计划

**Goal:** 给操作按钮与状态提示（alert / 隐藏 sheet badge）统一补上 `@lucide/vue` 图标。

**Architecture:** 各组件按需 import 内联使用，沿用现有 Trash2 模式；无集中封装、无新依赖、无测试改动。

**Tech Stack:** Vue 3 `<script setup>` + daisyUI 5 + `@lucide/vue`。

Spec: `docs/superpowers/specs/2026-09-16-ui-icons-design.md`

## Global Constraints

- 尺寸约定：按钮 `size-4`；alert `size-5 shrink-0`；badge `size-3`
- 带 loading 的按钮忙碌时 spinner 替换图标（不同显）
- 中性次要按钮（取消/关闭）、文字链接、标题、命中规则/已选列数 badge 不加图标
